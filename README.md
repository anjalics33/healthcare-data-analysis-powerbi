# Healthcare Data Analysis Dashboard – Power BI

## Project Overview
This project analyzes healthcare data using Microsoft Power BI to identify
patient trends, treatment costs, and healthcare-related insights.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Dataset
The dataset contains 500 records and 10 columns, including:
- Patient ID
- Age
- Gender
- Health Conditions
- Treatment Cost
- Hospital Visits
- Smoking Status
- Diabetes

## Project Work
- Cleaned and transformed data using Power Query
- Created DAX measures
- Built interactive dashboards
- Added KPIs, charts, and filters
- Analyzed treatment costs and patient trends
